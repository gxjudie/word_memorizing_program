# 文脈で覚える — 예문 기반 일본어 단어 암기 프로그램

예문(문맥) 중심으로 일본어 단어를 암기하는 AI 기반 학습 애플리케이션입니다.

## 왜 만드는가

Anki로 일본어를 공부하다 보면 단어 자체는 외워도, 막상 실제 문장을 읽을 때는 그 단어가 떠오르지 않는 경험을 하게 됩니다. 단어를 고립된 상태로 외우기 때문입니다.

이 프로그램은 **단어가 실제 문장 안에서 어떤 뜻으로, 어떤 맥락에서 쓰이는지**를 익히는 데 초점을 둡니다. 복습할 때마다 목표 단어가 들어간 새로운 예문을 보여주고, 사용자는 그 문맥 속에서 단어를 떠올리고 읽을 수 있는지 스스로 점검합니다.

기존에도 "카드에 단어를 넣으면 예문을 자동 생성"해주는 도구는 있습니다. 이 프로젝트는 거기서 한발 더 나아가, 예문을 **먼저** 보여주고 문맥 기반 회상을 유도하는 학습 흐름과 Anki식 간격 반복(spaced repetition)을 결합합니다.

## 핵심 기능

- **단어 등록**: 일본어 단어, 읽기, 뜻을 입력해 단어 모음에 추가합니다. (초기 버전은 간단한 입력 양식, 추후 Anki 덱 일괄 가져오기 지원 예정)
- **예문 우선 제시**: 복습 시 뜻보다 먼저 목표 단어가 포함된 일본어 예문을 보여주고, 목표 단어는 굵게/색상 등으로 강조합니다.
- **매번 새로운 예문**: 같은 단어를 다시 복습할 때는 매번 새 예문을 생성합니다. (문장을 통째로 외워버리는 것을 방지)
- **모르는 단어 조회**: 예문 속 목표 단어 외의 다른 단어를 클릭하면 뜻과 (한자인 경우) 후리가나를 보여줍니다.
- **자기 평가 & 간격 반복**: Anki처럼 "매우 어려움 ~ 매우 쉬움" 4단계로 스스로 평가하고, 그 결과에 따라 다음 복습 시점을 계산합니다.

## 학습 흐름

1. 오늘 복습할 단어(due words)를 모아 세션을 시작합니다.
2. 목표 단어가 포함된 새 예문이 뜻 없이 먼저 제시됩니다. 목표 단어는 강조 표시됩니다.
3. 모르는 단어를 클릭해 뜻과 후리가나를 확인할 수 있습니다.
4. 정답(읽기 + 뜻)을 공개한 뒤 4단계로 자기 평가합니다.
5. 평가 결과에 따라 다음 복습 날짜가 정해집니다.

## 상태

초기 설계 단계입니다. 요구사항 정의를 마쳤으며 기술 설계와 구현 계획이 이어집니다.

### 미정 사항

- **배포 형태**: 네이티브 Mac 앱 / 웹 기반 중 미정 (설계 단계에서 결정)
- **Anki 덱 가져오기**: 데모 단계에서는 뒤로 미루고, 간단한 입력 양식으로 먼저 구현
